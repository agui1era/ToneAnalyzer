# ToneAnalyzer - Multimodal Speech Tone & Audio Sentiment Analyzer

---

### 🌐 English

Audio processing engine evaluating vocal pitch, tone, and acoustic sentiment for customer service quality assurance.

#### Key Features:
* Acoustic feature extraction (MFCCs, Pitch)
* Real-time sentiment scoring
* Automated conversation reports

* **Tech Stack**: `Python` `Librosa` `PyTorch` `Audio Signal Processing`

---

### 🌐 Español

Motor de procesamiento de audio que evalúa tono vocal, ritmo y sentimiento acústico para control de calidad en atención al cliente.

* **Tecnologías**: `Python` `Librosa` `PyTorch` `Audio Signal Processing`
